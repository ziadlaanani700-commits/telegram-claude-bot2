# 🤖 Bot Telegram Claude IA

Bot Telegram intelligent propulsé par Claude (Anthropic).

## Fonctionnalités
- Répond à vos questions en français
- Mémoire de conversation (10 derniers messages)
- Fonctionne en privé et en groupe (mentionnez @votre_bot)
- Commande /start pour démarrer
- Commande /clear pour effacer la mémoire

## Déploiement sur Railway

1. Forkez ce repo sur GitHub
2. Allez sur railway.app et créez un nouveau projet
3. Connectez votre repo GitHub
4. Ajoutez les variables d'environnement :
   - TELEGRAM_TOKEN = votre token BotFather
   - ANTHROPIC_KEY = votre clé API Anthropic
5. Railway déploie automatiquement !
